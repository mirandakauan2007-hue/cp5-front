# Melodia

## Descrição
Landing page do aplicativo de música fictício **Melodia — Sua Música, Sua Forma** (Checkpoint 05, Front-end Design).

## Funcionalidades
- Navbar fixa, transparente no topo e com fundo ao rolar; menu hambúrguer funcional
- Hero com equalizador animado, seções de benefícios, funcionalidades, descoberta e depoimentos
- Player de demonstração (play/pause, progresso simulado, volume, playlist)
- Formulário com validação e mensagem de sucesso (envio simulado)
- Animações de entrada e suporte a `prefers-reduced-motion`

## Tecnologias
HTML5 · CSS3 · Tailwind CSS (CDN) · JavaScript · Font Awesome · Google Fonts (Manrope e Inter)

## Estrutura
```
index.html      página única
css/style.css   animações e componentes repetidos
js/script.js    navbar, menu, player, formulário
assets/         pasta para imagens e ícones (o projeto usa gradientes CSS)
```



## GitHub Pages
1. Crie um repositório e envie os arquivos na raiz.
2. Em *Settings → Pages*, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. Acesse a URL gerada pelo GitHub.
